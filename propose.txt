Crie uma aplicação em HTML, CSS e JavaScript que seja um app para treino de academia.

A página deve ser responsiva e deve ser compatível com todos os dispositivos.

A página deve ser feita em HTML, CSS e JavaScript.

Os exercícios serão feitos em 3 séries.
O app precisa ter espaço para eu anotar o peso e a quantidade de repetições que eu consegui fazer.
Os dados devem ser salvos no localStorage do navegador.
O app deve me lembrar da última série que eu fiz.
O app deve me lembrar dos últimos pesos e quantidades de repetições que eu fiz.
Vou abrir no meu celular.
Deve ter um botão para iniciar o treino. O botão de iniciar treino salva os dados do treino anterior para sugerir os mesmos valores para o próximo treino.
